## Build
1. **config.ts**: env `PORT` (default 3001), `TM_DB`, `TM_GROUP_CHAT_IDS` (comma list), `TM_PEOPLE` (`Name:handle,…`; cardCapable = handle is a phone number), `PUBLIC_BASE_URL`, `CARD_HMAC_SECRET`, `DEMO_FAST` (plan deadline 2 min vs 45 min), `CAMPUS_LAT/LNG` (default 35.9121, -79.0512), `GEMINI_API_KEY`, `TM_LINE_HANDLES` (Tablemate's own line numbers, for echo filtering). Helper `members(): Person[]`, `isEnrolledChat(id)`.
2. **db.ts**: tables `person`, `plan`, `option`, `skipped`, `vote`, `rsvp`, `card`, `plan_event`, `kv`, `msg` (dedupe) per spec §9 (B creates `fact`, `places_cache`; C creates `call`).
3. **transport.ts**: keep Kin's Spectrum cloud + local bootstrap and the fake transport. Local stream: **drop anything not in an enrolled group chat before logging** (spec §5.6). Expose `sendCard/editCard/sendText/sendEffect/sendAttachment` (cloud) — never a local send. The fake transport records every send for tests.
4. **router.ts**: dedupe by message id; **8 s debounce per chat** (env `TM_DEBOUNCE_MS`, tests use 0); route group bursts → `onGroupTurn(chatId, msgs)`; cloud DMs to Tablemate → log only (P2).
5. **brain.ts**: `onGroupTurn` = ONE Gemini call (`groupTurnSchema` per spec §10: intent, facts, text_votes, rsvps) with the burst + last 20 messages + active plan summary + now in America/New_York. Verify everything in code (members, quotes, option numbers). Save facts via `memory.saveFacts`. Text votes / RSVPs → `plan.ts`. Intent → offer (rule 9: confidence ≥ 0.8 + meal signal, ≤ 1 offer per chat per 6 h, none while a plan is active). **Regex fallback** when `geminiDisabled()` or the call fails (spec §10).
6. **plan.ts**: the state machine of spec §8 (`idle → offered → voting → booking → calling[i] → booked | asking_group | handed_back | cancelled`), every transition written to `plan_event` + a dashboard event. Party size = RSVPs "in" (organizer counts as in). Chosen time from time chips (default per spec §10). `book` only from the organizer's card token. On book: compute `windowStart/End = chosen ±30`, pick options in **vote order** (ties → search rank), skip places closed at chosen time, call `calls.placeCall(...)` for attempt 1; register `calls.setCallResultHandler` to advance: booked within window → `booked`; `offered_other_time` → `asking_group` (card buttons **Take <time>** / **Try next place**, organizer decides); `full|no_reservations|voicemail|no_answer|other` → next option (max 3) else `handed_back`; `card_required` → `handed_back`. On boot, plans stuck in `calling` → `handed_back`. `editAll(planId)` edits every member's card (caption/subcaption) after each change. Deadline timer (`DEMO_FAST`) only closes voting and nudges the organizer — it never books.
7. **cards/render.ts + server.ts**: card kinds per spec §13 (offer, plan vote screen with 3 option rows [emoji or photo, name, $$ · ★ · N min walk, why line], one "Skipping …" line, I'm in / Can't, time chips, organizer-only ✅ Book; calling; ask-group; booked with address, Maps link, 📅 Add to calendar (`/plan/:id/invite.ics`) and in-card CSS confetti; handed-back with tap-to-call links). Must fit 280×300 (reuse Kin's fit loop and glossy CSS from `kin_ref/cards/render.ts`). Routes: `/plan/:id?t=` (HTML), `/plan/:id/state?t=` (JSON, polled every 2 s while open), `POST /plan/:id/act?t=` ({action: offer_yes|offer_no|vote|rsvp|time|book|take_time|try_next|cancel, …}), `/plan/:id/invite.ics`, `/media/*`, `/health`, `/dash`, `/dash/events` (polling), localhost-only `POST /dash/reset` and `POST /dash/simulate` (injects a fake group message from a member: `{handle, text}` → goes through the router exactly like a real one — this is how we demo/test without phones). Delegate `/retell/*` to `calls.retellRoutes(req, url)`. Tokens: per-member HMAC (`plan id + handle`), so the server knows WHO tapped.
8. **dash/page.ts**: "Tablemate's thinking": state-machine strip with the current state lit, members + facts with quotes ("Nicole · vegetarian · “I'm vegetarian btw” · Thu 9:41 PM"), the filter decisions (from `SearchResult.filteredOut`), live votes/RSVPs, and a **live call panel** (events `call` + `transcript`). A small "simulate message" box (pick member, type text) that POSTs `/dash/simulate`. Reset button. Frutiger Aero styling like Kin's dashboard.
9. **main.ts**: boot db, `memory.initMemory()`, `calls.initCalls()`, transport, server; `void calls.ensureRetellSynced(config.publicBaseUrl)`; log "Tablemate is running · base … · dashboard on :3001/dash".
10. **seed**: `src/seed.ts` that resets the DB and adds people from `TM_PEOPLE` plus, if `TM_DEMO_SEED=1`, three demo facts with `source:"demo_seed"` (shown with a "demo seed" tag on the dashboard).
